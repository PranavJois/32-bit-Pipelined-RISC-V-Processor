# 32-bit-Pipelined-RISC-V-Processor

5-Stage Pipeline Datapath: (IF-ID-EX-MEM-WB)
1. Fetch Stage (IF)
2. Decode Stage (ID)
3. Execute Stage (EX)
4. Memory Stage (MEM)
5. Writeback Stage (WB)
